# GEMPRA visual asset

`gempra-field-emblem.png` was generated with the built-in ImageGen tool for this
project. The original generated PNG and its alpha transparency are preserved.
The dashboard uses deterministic LANCZOS derivatives: `gempra-emblem-96.png`
(96px for the 45px header at high DPI) and `gempra-favicon-32.png` (32px).
Both retain alpha transparency. The 1,254px source remains unchanged for future
exports; it is no longer downloaded by the page.

## Final generation prompt

Use case: logo-brand. Generate a single premium scientific instrument emblem for GEMPRA, a university geomagnetic monitoring dashboard. No text, no letters, no numbers. A precise circular planet cross-section constructed from elegant cyan and ice-white magnetic field loops, with a single subtle amber observation node and a clean central waveform slit. Flat crisp graphic, sophisticated research observatory identity, simple enough to read at 40 pixels, centered with generous transparent padding, square composition. Genuine transparent background, no opaque backdrop, no mockup, no gloss, no extruded 3D, no badge border, no extra symbols. Cyan #57d9dc, white #edf7ff, tiny amber #e7b36a. This will be used on a dark navy interface.
